# Towers of the Wild — Climb Tall Towers for Loot

Towers of the Wild 9minecraft Mod scatters tall stone towers across the world, one per biome type, each with a ladder running up the inside and a chest waiting at the top. They are the kind of landmark you steer towards from half a kilometre away - you can see one long before you can reach it, and getting up it is its own small expedition. There are twenty-two variants and each is built from what the surrounding land is made of.

## What this build is

An unofficial rebuild of **celsiusqc**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
